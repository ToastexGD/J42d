# J42d hardware

From the tvOS 26.6 (23L773) `DeviceTree.j42dap` and kernelcache. Regenerate with `tools/fetch-fw.sh`.

## Peripherals

| Block | Hookup | Linux |
|---|---|---|
| PMU | Dialog D2186 (`pmu,d2186`, Linux `adi`) on i2c0 @ 0x74, IRQ on SoC GPIO 67 | RTC, nvmem, GPIO |
| Ethernet | Microchip LAN9730 (0424:9730), HSIC, EHCI2 port 1 | `smsc95xx` |
| Wi-Fi | BCM4350 on apcie port 1, Gen1, PERST GPIO 77, CLKREQ GPIO 41, WAKE GPIO 63, REG_ON PMU GPIO 3 | needs apcie host driver |
| Bluetooth | `bluetooth,n88` on uart1, 3 Mbaud, power PMU GPIO 2, BT_WAKE SoC GPIO 48 | TBA |
| IR / front MCU | `mcu-nmi` on uart3, BSL on uart0, IRQ SoC GPIO 49, reset GPIO 130, TCK GPIO 50. AppleTVIR only exposes reset/TCK, the IR protocol is in a tvOS userspace daemon | TBA |
| HDMI | SoC DisplayPort -> MegaChips STDP2700, STDP2700 reset PMU GPIO 5 | iBoot framebuffer |
| Power monitor | `pmon,1` on uart4, reset GPIO 128, ISP GPIO 129 | - |
| Debug console | uart6 | serial6 |
| Storage | ANS (`iop,s5l8960x`) | WIP upstream |
| GPU | PowerVR GX6450 (`sgx`) | - |

## PMU GPIO

| Register | Use |
|---|---|
| 0x400 + 2n | config for pin n, n = 0..20 |
| bit 7 | 1 = input |
| bit 4 | alternate function |
| bit 1 | output level |
| bits 2, 0 | kept by iOS on every write |
| 0x63 + n / 8 | input level, bit n % 8 |

ADT `function-*` flags for PMU GPIOs: bit 8 = active high, low byte 1 = output driven deasserted at start, 0 = input.

| PMU GPIO | Use | Active |
|---|---|---|
| 2 | BT power | high |
| 3 | WLAN REG_ON | high |
| 5 | STDP2700 reset | low |
| 10 | LAN9730 reset | low |
| 16 | AC detect | |
| 17 | LAN9730 PME | high |

PMU event names (1-based): gpio7 bluetooth, gpio8 wlan, gpio12 dock, gpio17 ac.

## USB complex

| Address | Use |
|---|---|
| 0x20c000000 | EHCI0 ctl |
| 0x20c000008 | OHCI0 ctl |
| 0x20c000018 | EHCI2 ctl: +0 bit 1 = stop (set while idle), +4 = cfg-incr (0xf) |
| 0x20c000020 | OTG device ctl |
| 0x20c000030 | OTG PHY |
| 0x20c000060 | HSIC1 PHY (lan0) |
| 0x20c900000 | DMA remap: 0x1c/0x3c/0x5c/0x7c/0x9c = 0x100 \| addr[35:32] |

`clock-mask` bit -> PMGR domain: 0 USBCTRL, 1 USBOTG, 2 USB2HOST0, 3 USB2HOST0_OHCI, 4 USB2HOST1, 5 USB2HOST2, 6 HSIC0_PHY, 7 HSIC1_PHY.

HSIC PHY on: `ctl |= 0x3`, optional `cfg -> +8`, `ctl &= ~0x26`, 20 us, `ctl &= ~0x1`, 1 ms.
HSIC PHY off: `ctl |= 0x7`.

## USB-C port

OTG PHY (`otgphyctrl`): regs at 0x20c000030, `USB_CTL` at 0x20e031000. EHCI0/OHCI0 share the port with the dwc2 device controller.

Host mode: `USB_CTL |= 1`, `cfg0-host -> +0x8`, `cfg1-host -> +0xc`, `0 -> +0x1c`, `ctl |= 1`, delay, `ctl &= ~1`, delay.
Device mode: `USB_CTL &= ~1` and the device tunables.
